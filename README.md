# banza.co · marca

Este repositório aloja os ativos oficiais da marca **banza.co**. Os ficheiros em `logo/` são servidos em URLs públicos e estáveis pelo [jsDelivr](https://www.jsdelivr.com/), para utilização em mensagens de correio eletrónico em HTML.

Cada ficheiro está disponível em:

```
https://cdn.jsdelivr.net/gh/lbanza/banza-brand@main/logo/<ficheiro>
```

### Marcas dos relatórios

Ícones de linha e lockups dos cinco relatórios — briefing, cve, tendencias, pesquisa e algarve — e do sublogo Executive Exposure, para fundo escuro e para fundo claro. Cada marca está em SVG, PNG e PNG a 2× (72 ficheiros em `logo/relatorios/`).

Cada ficheiro está disponível em:

```
https://cdn.jsdelivr.net/gh/lbanza/banza-brand@main/logo/relatorios/<ficheiro>
```

O ícone mede 48×48 px (96×96 px a 2×). O lockup mede 240×48 px (480×96 px a 2×).
